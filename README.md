# 7セグメントデジタル表示プロジェクト (seven-segments)

このプロジェクトは、CSSマスクとグラデーションを用いた美しい発光エフェクトを持つ、7セグメントのデジタル数字表示（デジタルクロック、グリッドアート等）を実装したHTML/CSS/JSファイルのコレクションです。

## HTMLファイルの特徴と解説

プロジェクト内にある各HTMLファイルの特徴、レイアウト手法、およびアニメーション/パフォーマンス特性は以下の通りです。

| ファイル名 | 役割 / 特徴 | レイアウト手法 | 更新・パフォーマンス特性 |
| :--- | :--- | :--- | :--- |
| **[index.html](https://oharato.github.io/seven-segments/index.html)** | デモ・コンポーネントカタログ | インライン配置 + 装飾パネル | 静的表示。基本パーツ・各テーマ・サイズ・文字パターンの確認用 |
| **[clock.html](https://oharato.github.io/seven-segments/clock.html)** | デジタル時計 (時・分・秒) | CSS Grid (画面中央配置) | 1秒ごとの時間取得・DOM一括書き換え (極めて軽量) |
| **[grid.html](https://oharato.github.io/seven-segments/grid.html)** | ランダムグリッドアート | 絶対座標 (`position: absolute`) | 各桁が異なる周期（0.1s〜10s）で独立して数値更新を行うDOMアニメーション |
| **[grid2.html](https://oharato.github.io/seven-segments/grid2.html)** | タイル状グリッドアート | CSS Grid (`1fr` 等分割) | 全画面等分割タイル配置。CSS Containment とラグ対策ループを導入した最適化DOM版 |
| **[grid-fast.html](https://oharato.github.io/seven-segments/grid-fast.html)** | 超高速グリッドアート | HTML5 Canvas | Canvas pre-rendering キャッシュを使用した、数千桁でも常時60FPSを超える極限最適化版 |

---

### 詳細解説

### 1. `index.html` (コンポーネントカタログ)
- **特徴**: プロジェクトで使われているデジタル数字（7セグメントディスプレイ）のショーケースです。
- **内容**:
  - 各種カラーテーマ（標準赤、アンバー、シアン、グリーン、アイス）
  - サイズバリエーション（標準、大 `lg`、小 `sm`）
  - 16進数文字（`0-9`, `A-F`）および特殊記号（`-`, `_`）の表示
- **仕組み**: 立体感のある外枠パネルの中に、CSS（[digit.css](https://oharato.github.io/seven-segments/digit.css)）でスタイリングされたデジタル数字を配置しています。

### 2. `clock.html` (デジタルクロック)
- **特徴**: 時・分・秒（HH:MM:SS）を表示する実用的なデジタル時計です。
- **レイアウト**: 画面の上下左右中央にガラス感のあるダークパネルを配置し、その中にコロン（点滅アニメーション付き）と数字を並べています。
- **仕組み**: `setInterval` を用いて1秒ごとに現在時刻を取得し、DOMの `data-char` 属性を書き換えています。非常に軽量で動作します。

### 3. `grid.html` (ランダムグリッド)
- **特徴**: 画面全体にデジタル数字が星空のように散りばめられ、それぞれの数字が異なる速度でカウントアップする抽象的なビジュアルアートです。
- **レイアウト**: `Math.random()` によって画面内の絶対座標（`%` 指定）およびサイズ（`sm`, `normal`, `lg`）、色（テーマ）を完全にランダムに配置しています（計120個）。
- **アニメーション**: `requestAnimationFrame` で時間を計測し、各数字に割り当てられた更新周期ごとに独立して数値を加算しています。

### 4. `grid2.html` (タイルグリッド - DOM最適化版)
- **特徴**: 画面全体を隙間なく埋め尽くすようにデジタル数字をタイル状に敷き詰めたビジュアルです。
- **レイアウト**:
  - CSS Grid を用い、画面アスペクト比を崩さないよう幅 `44px`、高さ `78px` に近い割合で画面全体を等分割（`1fr`）します。
  - 画面の外周には `16px` の余白を設定し、隣り合う数字の間には `padding` によって適度なマージンを確保しています。
- **パフォーマンス最適化**:
  - **CSS Containment (`contain: layout style;`)**: デジタル数字が更新された際、ブラウザの再計算・再レンダリング処理が各セルの内部だけで完結するように制限し、ドキュメント全体へのレイアウト伝播を防いでいます。
  - **ラグ対策ループ**: ブラウザのタブが非アクティブになったりラグが発生した際、過去の遅れた更新を一括スキップして最新の状態に「1度だけ」更新する制御を入れることで、復帰時のDOM更新ラッシュ（キャッチアップ・ストーム）による遅延を防ぎます。

### 5. `grid-fast.html` (タイルグリッド - Canvas極限最適化版)
- **特徴**: `grid2.html` と同じタイル状の敷き詰めレイアウトですが、表示するデジタル数字の数が数千個になっても全く重くならない、圧倒的なパフォーマンスを誇るバージョンです。
- **仕組みと最適化技術**:
  - **HTML5 Canvas**: 数千のDOMノードを排し、画面全体を単一の Canvas 上で描画します。
  - **オフスクリーン・プレレンダリング（テクスチャキャッシュ）**: 描画負荷の非常に高い「斜め変形（skew）」や「多層ネオングロー（`drop-shadow`）」の計算をアニメーションループ中には行いません。リサイズ時にメモリ上の仮想キャンバスに「5色 × 10文字 = 50通り」の完成済みの数字画像をあらかじめレンダリング（キャッシュ）しておき、毎フレームのループではそれを `ctx.drawImage` でただ高速コピーするだけにしています。
  - **差分レンダリング（省電力）**: 毎フレームのループで「値が変わった数字」が1つも存在しない場合、画面のクリアや再描画を一切スキップします。これにより、動きのない時間帯はGPU/CPUパワーを全く消費しません。
  - **High-DPI / Retina対応**: デバイスのピクセル比（`devicePixelRatio`）を検出し、4KやRetinaディスプレイでもにじみのない極めて鮮明でシャープな発光を表現します。

## プレビュー方法

ローカルサーバーを立ち上げてブラウザでプレビューできます：

```bash
# Vercel の serve パッケージを使用してサーバーを起動
npx serve
```

起動後、以下のURLにアクセスして各デモを閲覧できます。
- インデックス・カタログ: `http://localhost:3000/index.html`
- デジタル時計: `http://localhost:3000/clock.html`
- ランダムグリッド: `http://localhost:3000/grid.html`
- DOMタイルグリッド: `http://localhost:3000/grid2.html`
- 超高速Canvasグリッド: `http://localhost:3000/grid-fast.html`
